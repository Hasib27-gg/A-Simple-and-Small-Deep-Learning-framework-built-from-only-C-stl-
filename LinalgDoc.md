# Welcome To The Documentation of Linear Algebra
## Breif before it:
This documentation is to showcase the usage of each functions, classes etc. in the LinearAlgebra folder of Source Code. Since I wanted to provide explanation , this documentation is seperated into different file sections. Click there to get there:

## [1. Matrix](LinalgMatrixDoc.md)
### Breif: 
This is the core or the "kernel" of the Linear Algebra Engine. It provides classes and functions which are the most essential beings throughout the whole project. The documentation is divided into different sections, as they are technical.
## [2. LinalgAppliables](LinalgAppliablesDoc.md)
### Breif: 
Provides essential appliables functors for the kernel method ```Linalg::map(...)```
## [3. LinalgZipables](LinalgZipablesDoc.md)
### Breif: 
Provides essential appliables functors for the kernel method ```Linalg::zip_no_accum(...)``` and   ```Linalg::zip_with_accum(...)```
## [4. LinalgReductions](LinalgReductionsDoc.md)
### Breif: 
This is handcoded implementations of some utilities for the kenrel method: ```Linalg::reduce_no_accum(...)``` and   ```Linalg::reduce_with_accum(...)```
## [5. LinalgStreams](LinalgStreamsDoc.md)
### Breif:
A very useful uitily for the Linalg::Matrix for row or column-wise operations. 
## [6. LinalgValueGenerators](LinalgValueGeneratorsDoc.md)
### Breif:
A very short utility for creating and initalizing matricies
## [7. MatrixIterator](MatrixIteratorDoc.md)
### Breif: 
An iterator implementation for the matrix. Not meant to be compatible with STL but still useful.
